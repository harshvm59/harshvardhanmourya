# Harsha's AI Investment Intelligence Terminal

A self-updating investment research website that scrapes YouTube, RSS news, and live stock data every morning, extracts AI investment themes being discussed by Jensen Huang, Elon Musk, Sam Altman, Cathie Wood, and others, and maps them against a real portfolio. Updated daily via Mac cron and published to GitHub Pages automatically.

Built for a serious investor who doesn't have time to watch YouTube daily — this terminal IS the daily briefing.

---

## Quick Setup

1. **Clone and enter the directory**
   ```bash
   git clone https://github.com/harshvm59/harshvardhanmourya.git
   cd harshvardhanmourya/ai-investment-terminal
   ```

2. **Run setup (installs deps + registers cron)**
   ```bash
   bash setup.sh
   ```

3. **Add your YouTube API key to `.env`**
   ```
   YOUTUBE_API_KEY=AIza...your_key_here
   ```

4. **Test the data fetcher (no YouTube needed)**
   ```bash
   python3 fetch_data.py --skip-youtube
   ```

5. **Open in browser**
   ```bash
   open index.html
   ```

## Getting a YouTube API Key

1. Go to [https://console.cloud.google.com](https://console.cloud.google.com)
2. Create a new project (or select existing)
3. Go to **APIs & Services → Library**
4. Search for **YouTube Data API v3** → Enable it
5. Go to **APIs & Services → Credentials → Create Credentials → API Key**
6. Copy the key into your `.env` file

The free tier allows 10,000 units/day. Each search costs ~100 units. The script uses ~14 searches per run, so you have a large headroom.

## Daily Automation

`setup.sh` registers a cron job that runs `deploy.sh` at 7:00 AM every day:

```bash
bash setup.sh
```

What the cron does:
1. Runs `fetch_data.py` to pull fresh stock prices, YouTube videos, and news sentiment
2. Commits `data/data.json` to git
3. Pushes to GitHub, which triggers GitHub Pages to update

To verify the cron is registered:
```bash
crontab -l
```

Logs are written to `logs/cron.log`.

## GitHub Pages Setup

1. Push this folder to your GitHub repo
2. Go to your repo on GitHub → **Settings → Pages**
3. Under **Source**: select `Deploy from a branch`
4. Branch: `main`, Folder: `/ (root)` → **Save**
5. Wait ~2 minutes → your site is live at `https://yourusername.github.io/reponame/ai-investment-terminal/`

Make sure `data/data.json` is committed (it's NOT in `.gitignore` — that's intentional).

## Troubleshooting

**`ModuleNotFoundError: No module named 'yfinance'`**
```bash
pip3 install -r requirements.txt
```

**`data.json` shows no YouTube videos**
- Check your `YOUTUBE_API_KEY` in `.env`
- Run `python3 fetch_data.py` (not with `--skip-youtube`)
- Check quota at [https://console.cloud.google.com](https://console.cloud.google.com)

**Stock prices are stale**
- Markets are closed on weekends. Run on a weekday morning after 9:30 AM ET.
- yfinance occasionally has delays. Re-run after a few minutes.

**Cron job not running**
```bash
# Check if registered
crontab -l

# Check logs
cat logs/cron.log

# Re-register
bash setup.sh
```

**GitHub Pages not updating**
- Ensure `data/data.json` is committed and pushed
- Check repo Actions tab for any failed deployments
- Hard refresh browser: Cmd+Shift+R (Mac) / Ctrl+Shift+R (Windows)
